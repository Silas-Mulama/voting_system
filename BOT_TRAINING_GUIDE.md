# Chatbot Training & Learning System - Complete Guide

## Overview

The chatbot system has been enhanced with an **admin-controlled training mechanism**. The bot does NOT auto-learn from users. Instead, it follows a controlled workflow where:

1. **User asks question** → Bot evaluates confidence
2. **Low confidence detected** → Question saved for admin review
3. **Admin provides answer** → Answer stored in database
4. **Admin exports training** → Approved Q&A exported to YAML
5. **Bot retrains** → Server restart loads new training data

This ensures only **quality, accurate answers** are added to the bot's knowledge base.

---

## Architecture

### 1. Confidence Scoring System

The chatbot returns a confidence score (0.0 - 1.0) for each response:

- **1.0** = Exact match (user input exactly matches a trained keyword)
- **0.85** = Partial match (keyword found in user input)
- **0.0** = No match (default fallback response)

**Threshold**: 0.60 (60%)

Any response with confidence < 0.60 is considered "unanswered" and saved for admin review.

### 2. Database Model: BotQuestion

Located in: `core/models.py`

```python
class BotQuestion(models.Model):
    question = models.TextField(unique=True)  # User's question
    answer = models.TextField(blank=True, null=True)  # Admin-provided answer
    is_answered = models.BooleanField(default=False)  # Admin approval status
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)
```

### 3. Training Data Location

Dynamic training data file:
```
core/training_data/dynamic_training.yml
```

This file is auto-generated by the `export_bot_training` command and loaded on bot initialization.

## Step-by-Step Usage

### STEP 1: Student/Admin Asks Question

User submits a question in the chat interface (any page with `/chat/` or `/admin/chat/`).

**Example:**
```
User: "How do I request a recount?"
```

### STEP 2: Bot Evaluates Confidence

The chatbot's `get_response()` method:
1. Normalizes the question (lowercase, strip whitespace)
2. Checks for exact and partial keyword matches
3. Returns: `{'response': str, 'confidence': float}`

**Example Response:**
```python
{
    'response': "I'm not sure about that. I can help with...",
    'confidence': 0.0  # Low confidence!
}
```

### STEP 3: Low Confidence Questions Saved

In `core/views.py`, if `confidence < 0.60`:

```python
if confidence < voting_bot.confidence_threshold:
    BotQuestion.objects.get_or_create(
        question=user_message,
        defaults={'answer': None, 'is_answered': False}
    )
    # User sees: "Your question has been saved for admin review"
```

Only questions < 60% confidence are saved (not duplicates due to unique constraint).

### STEP 4: Admin Answers Questions

**Access Django Admin:**
```
http://127.0.0.1:8000/admin/core/botquestion/
```

**Interface:**
- List view shows: Status | Question | Is Answered | Created Date
- Filters available: Answered / Unanswered
- Editable fields: Answer, Is Answered checkbox

**To Answer a Question:**

1. Click on an **Unanswered** question
2. Scroll to **"Answer"** field
3. Type the answer you want the bot to learn
4. Check **"Is Answered"** checkbox
5. Click **Save**

**Example:**
```
Question: "How do I request a recount?"
Answer: "Contact the election administrator. Recounts are reviewed on a case-by-case basis."
Is Answered: ✓ Checked
```

### STEP 5: Export Training Data

Once admins have answered several questions, export them:

```bash
python manage.py export_bot_training
```

**Output Example:**
```
✅ Successfully exported 5 Q&A pairs!
📁 File saved to: core/training_data/dynamic_training.yml
⚠️  IMPORTANT: Restart your Django server for the chatbot to use the new training data.
```

**Generated YAML file:**
```yaml
categories:
- dynamic_training
conversations:
- - "How do I request a recount?"
  - "Contact the election administrator. Recounts are reviewed on a case-by-case basis."
- - "Can I change my vote after closing time?"
  - "No, voting is closed. You must vote before the deadline."
```

### STEP 6: Restart Django Server

The chatbot loads training data during initialization. Restart to load new Q&A:

```bash
python manage.py runserver
```

**In the console, you should see:**
```
Starting development server at http://127.0.0.1:8000/
Quit the server with CTRL-BREAK.
```

The dynamic training data is now loaded into memory.

### STEP 7: Test the Bot

Ask the newly trained question in the chat:

**Before Training:**
```
User: "How do I request a recount?"
Bot: "I'm not sure about that. I can help with questions about..."
Confidence: 0.0
```

**After Training & Server Restart:**
```
User: "How do I request a recount?"
Bot: "Contact the election administrator. Recounts are reviewed on a case-by-case basis."
Confidence: 0.85 (partial match)
```

### Dynamic Training Loading

**Function:** `load_dynamic_training_data()` in `core/chatbot.py`

```python
def load_dynamic_training_data():
    """Load admin-approved Q&A from YAML file."""
    training_file = os.path.join(settings.BASE_DIR, 'core', 'training_data', 'dynamic_training.yml')
    
    if not os.path.exists(training_file):
        return {}  # No training data yet
    
    with open(training_file, 'r') as f:
        data = yaml.safe_load(f)
    
    # Convert YAML to {question: answer} dict
    training_dict = {}
    for q, a in data['conversations']:
        training_dict[q.lower().strip()] = a
    
    return training_dict
```

## Important Notes

### ⚠️ Critical Rules

1. **NO Auto-Learning**: Questions are only saved, never auto-answered.
2. **Admin-Only Training**: Only admins can add approved answers in Django Admin.
3. **Controlled Rollout**: Answers only affect the bot after admin exports and server restarts.
4. **Quality Control**: Each answer is manually reviewed before deployment.

**Check if training is working:**

1. Count unanswered questions:
   ```bash

   >>> BotQuestion.objects.filter(is_answered=False).count()
   ```

2. Check training data size:
   ```bash
   python manage.py shell
   ```

   - Restart server immediately after export

   - Identify gaps in bot knowledge
   - Refine answers based on follow-up questions

## Troubleshooting

### Issue: Export fails with "No answered questions found"

**Solution:** Make sure you've checked the "Is Answered" checkbox before saving.

### Issue: New training data not used after restart

**Solution:** 
1. Check that export command ran successfully
2. Verify file exists: `core/training_data/dynamic_training.yml`
3. Restart Django: `python manage.py runserver`
4. Check console for errors

### Issue: Question appears with every ask

**Solution:** Question may not be saved due to duplicate. Check:
```bash
python manage.py shell
>>> from core.models import BotQuestion
>>> BotQuestion.objects.filter(question__icontains="your question")
```

### Issue: Confidence score always 0.0

**Solution:** Bot responses only have low confidence for truly unknown questions. Make sure:
1. Question doesn't contain any known keywords
2. Base responses are still intact
3. Check if dynamic_training.yml is loading (should have no errors in console)
